# vtcon RIP-0 fixtures

Hand-written 2026-11-09 by the DCTelnet session for vtcon RIP-0. Own content, no third-party art, licence same as vtcon.

Syntax follows the RIPscrip 1.54 grammar as documented in docs/research (spec text found was Rev 1.53): lines start `!|`, base-36 MegaNum with fixed per-command widths, level prefixes such as `|1U`, `\` continuation, `\!` `\|` `\\` escapes. Canvas is 640x350, 16-colour EGA. Coordinates are written as 2-digit MegaNum (`0A` = 10, `50` = 180).

Pixel expectations marked (UNVERIFIED) depend on geometry not confirmed against a real board (Bresenham rounding, arc end points, font cell); test those with a tolerance or only check the bounding box.

| 01-line-grammar.rip | Plain text lines ignored, blank line, `!|` command chaining with `|`, `*` reset, `E` erase, `#` end | Black screen. White square (10,10)-(180,180) with white diagonal to its corner. Light-red anti-diagonal (180,10)-(10,180). Yellow circle centre (95,95) radius 60 (UNVERIFIED rim pixels). | 07-buttons.rip | `1K`, `1B`, three `1U`, two overlapping `1M` | Gray background. Two buttons with labels "Alpha" (hotkey A, host command `alpha^M`) and "Beta" (hotkey B, `beta^M`) at (20,20)-(80,40) and (20,60)-(80,80).
