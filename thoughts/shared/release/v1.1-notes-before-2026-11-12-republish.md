UP-Term 1.1 with the Amarchy desktop suite, built from spotUP/UP-Term 5f5a7061 (2026-11-12).

Install: unpack up-term.lha and run its Install script. The add-on archives (up-claude, up-dopus, up-nvim, up-pi, up-python, up-uhc) install the same way, or through upkg from this feed. up-term-src.lha holds the sources of everything shipped.

Offline install: up-term-full.lha is up-term.lha plus a Packages drawer with all 28 packages. Run Install, then in a Shell CD to the unpacked drawer and Execute Install-Packages. Known faults in this build (emulated AmigaOS 3.2, 2026-11-12): git, nvim, perl and vim do not install through Install-Packages; uhc needs a network download; the Directory Opus package waits for a click in its own installer; starting the base install from a Shell with a relative drawer (Execute Files/install.dos Files) fails, use the Install icon or a full path. Fixes are in work.

Network install: up-term-boot.lha (5.9 MB) holds a small downloader and the AmiNetXDuo 1.0.0-rc2 TCP/IP stack. Unpack it, CD into the drawer and run Execute Get-UP-Term TO <drawer with about 110 MB free>. When the Amiga has no TCP/IP stack, it first starts AmiNetXDuo's own installer (it asks for the network card's SANA-II driver and for DHCP or a fixed address, and adds its lines to S:User-Startup), then asks for a reboot; run Get-UP-Term again after the reboot. With a stack it installs root certificates to ENVARC:certs when none are there, fetches up-term.lha over https with the certificate check on, unpacks it and starts the install (to SYS:UP-Term). Needs lha in the path and a 68020 or better. Its bebboget is a modified build of Stefan Franke's bebboget 1.11 (GPL v3 or later); the source change is in the archive as bebboget-up-term.diff. Tested on one emulated AmigaOS 3.2 system: the download with a stack present, and the AmiNetXDuo install up to the reboot message. Not run: the download over AmiNetXDuo with a real network card, the second run after the reboot, the ALL switch (install every package).

The remaining assets are the upkg feed (Packages, Packages.gz, upkg-index.txt and the .ipk packages) read by UP-Term:etc/upkg.conf from releases/latest/download.

Changes since 1.0

- amarchy-flat: flat look for more system gadgets. Time Preferences has a full-width month row, check boxes are square and visible when not ticked, and read-only text boxes look like input fields.
- amarchy-flat: safer unload path.
- Terminal: RIP window reset fix, kitty mouse and picture fixes.
- Directory Opus package 1.1: toolbar icon sets in more sizes.

Known issues

- Programs built with MUI (for example JpegLibraryPrefs) are not flattened yet.
- A check box created before amarchy-flat starts keeps the ROM look until its window is reopened.
- These host-side test suites fail on this revision and are under triage; none of them is new in 1.1: test_rig_fsuae_log, test_amarchy_menu_stamp, test_wb_lock_guard, test_ibase_lock_guard, test_flat_on_hang_wild_call, test_amarchy_gui_rebind, test_rig_browse_base, test_rig_browse_free, test_rig_upterm, test_rig_kit, test_unorm. The three guard suites (wb_lock_guard, ibase_lock_guard, flat_on_hang_wild_call) point at calls that may be unsafe in rare conditions.
