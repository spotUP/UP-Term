# vsh: a native AmigaOS shell with Unix grammar

## Goal

The owner's goal (2026-09-29): "a fully featured unix level zshell level terminal on my amiga". The
terminal side (XCON, phase A) is done; vsh is the shell that makes it feel like one: POSIX `sh`
grammar, pipes, redirection, globbing, variables, job control, running Amiga commands, Resident
commands and ixemul programs side by side, with zsh-class interactive editing.

## Decisions (made under the owner's delegation, 2026-09-29)

1. **Native AmigaOS program, vbcc, 68020+, KS 3.x.** An ixemul shell (pdksh, tcsh) is bound to vfork
   and cannot run Resident commands; a native one owns process creation (research section C).
2. **Interactive editing is XCON's** (H7: history with prefix search, Ctrl-R, grey suggestions, word
   motions, undo, completion worker, command colouring). vsh reads lines in cooked mode and gets all
   of it for free. Shell-specific completion (variables, builtins, aliases) comes later through a
   small handler hook (S9), not a second line editor.
3. **Processes without fork:**
   - external commands: `SystemTags` with `NP_*`/`SYS_*` tags, synchronous or `SYS_Asynch`;
   - Resident commands: `FindSegment` + `RunCommand`, as the AmigaDOS Shell does;
   - pipelines: one process per stage, joined by `PIPE:` channels (queue-handler, KS 3.0+);
   - subshells and command substitution: a new process running the interpreter on a copy of the
     parsed tree, as abcsh does (`CreateNewProcTags`, `NP_Entry`).
4. **Exit status:** `$?` is the Amiga return code (0/5/10/20 pass through); a Unix program's exit code
   arrives the same way through ixemul.
5. **ixemul programs:** they glob their own argv (`__ix_cli_parse`), so vsh passes their arguments
   quoted after its own expansion; detection by the `ixemul.library` string in the hunk file is not
   needed if every argument is always quoted for AmigaDOS.
6. **Paths:** Unix-style input is accepted (`/`, `~`, `..`, `.`) and mapped to AmigaDOS (`SYS:`,
   `/` = parent, `""` = current) at the word level; AmigaDOS forms pass through untouched.
