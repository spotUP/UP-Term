# A2 progress ledger

Plan: thoughts/shared/plans/2026-10-04-a2-native-claude-client.md. Branch
feature/a2-claude-client (from main 6d18783). Rules for this run: no emulator, no real
API call, no key anywhere; keep out of render/amiga_render.c, render/vtwin.c, engine/.

## Decisions taken during the run (do not re-litigate)

- No A1 telnet client exists yet (feature/a1-claude-lan has no commits; its worktree has
  only tools/capture_claude.py) and UP-Term has no native network code: the bsdsocket
  code is new, written against Roadshow's netinclude (NDK3.2R4
  SANA+RoadshowTCP-IP/netinclude, vbcc inlines), which also covers Miami/AmiTCP.
- The AmiSSL SDK is NOT on this Mac (only the user libraries 5.25 in ~/Downloads/testbbs).
  TLS sits behind claude/tls.h: tls_amissl.c is built only with `make amiga AMISSL_SDK=<dir>`;
  the default build links tls_none.c (an https URL then fails with a clear message).
  The OpenSSL part of tls_amissl.c is syntax-checked on the host against Homebrew OpenSSL.
- Plain http:// URLs are allowed (URL= argument) so the owner can drive the full program on
  the rig against tools/claude_fixture.py (recorded streams, no key, no Anthropic call).
- The markdown renderer (feature/highlight-markdown) has not landed: its interface is
  md_render(whole document). The client has a renderer hook (claude/ui.h cl_render) with a
  plain-text renderer; the markdown renderer plugs in there when it lands.
- History is append-only. A turn that does not complete (Ctrl+C, refusal, error event,
  max_tokens with a tool_use) is not appended; the history rolls back to the last complete
  request. An unanswered plain prompt is dropped; a trailing tool_result message is kept and
  the next prompt is added to it as a text block (it follows every thinking block, so no
  signature's prefix changes).
- Server-side fallback echo rule (API docs): blocks of type thinking / redacted_thinking /
  tool_use / unknown that come BEFORE the last `fallback` block of a turn are left out when
  that turn is appended (once, at append time -- earlier turns are never touched).
- Top-level `"cache_control":{"type":"ephemeral"}` is added to the body besides the system
  prompt's: every tool round resends the history, so caching it is the owner's cost saving.
- run_command: the command goes into a T: script run as `vsh <script>` (no quoting), output
  to a T: file, from a runner process exactly as vsh runs its own jobs (synchronous
  SystemTags with the Shell process named; the runner replies with the return code).
  Timeout (60 s) and Ctrl+C send that process a break; a command that ignores the break for
  10 s is left running and reported. (A first draft used NP_ExitCode; replaced by vsh's
  rig-tested pattern before landing.)
