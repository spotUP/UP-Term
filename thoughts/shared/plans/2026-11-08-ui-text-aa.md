# UI text antialiasing: all window text, one switch, bitmap fonts (s63)

Owner request 2026-11-08: "fix the stuff listed under not covered and allow users to antialias bitmap fonts as well
using the same routine we use for the icon texts".

## Owner decisions (AskUserQuestion, 2026-11-08)

- Scope of window text: **all window text** (every JAM1/JAM2 Text call in every window, every program), not only the
  flat-drawn titles/buttons. Accepted cost: every qualifying Text pays a read-back and blend.
- Switch: **one prefs key `ui-antialias = on|off`, default on**, with a settings toggle. Covers menus, window titles,
  gadget labels, all window text, icon labels, bitmap fonts. (`outline-antialias` stays the terminal's own key.)
- Bitmap fonts: **everywhere AA is on**, true-colour and pen screens (pen screens use aa_ink / icl shade pens).

## The routine reused

RL21 iclabel (amarchy/iclabel_core.c, amarchy/flat.c icl_label): read box before, stock Text, read after, icl_mask,
icl_coverage (corner fill ICL_COV_ONE 96 / ICL_COV_TWO 160), icl_blend_rgb or icl_blend_pens with the per-screen pen
cache. No copy: the menus call icl_coverage on the bitmap glyph coverage too.

## Implementation defaults (mine, not vetoed)

- The task gate in icl_accept goes; the switch (flat_state field from `ui-antialias`) replaces it. Mode, pen, and
  box checks stay (no COMPLEMENT/INVERSVID, APen != BPen).
- The inner-area check widens to the whole window (titles live in the border); the box must still lie inside the
  window and the layer's bounds.
- Wide boxes: an area limit, not strips (decided while building). ICL_MAXW 1024, ICL_MAXH 24, ICL_MAXPX 320 x 24 pixels,
  so a 960 x 8 or 480 x 16 title blends in one stock draw with no buffer growth; larger boxes run stock.
- tx_title and tx_armed only draw the band and set pens; flat_tx_c then runs the one text step (icl_label, else stock)
  and restores the caller's pens, so their frames unwind first (flat-budget chain 312, headroom 72).
- Stack: the work stays in the S62-FLAT-RF-TX-BUDGET split helpers; nothing large on the caller's stack.
