# U2: Unifont pages -- ledger

Branch `feature/u2-unifont` off main. Source item: plan 2026-09-28-vtcon.md, UNICODE U2.
Done = converter + pages (make target), cache, fallback chain hooked into the renderer,
kit Installer part, host tests (converter golden bytes, cache, fallback order, one
reachability test with a loader call-count sentinel), make test / test-ref / amiga green.

## Decisions (do not re-litigate)

- Source: GNU Unifont 17.0.05, `unifont_all-17.0.05.hex.gz` (sha256 7b182454...e574),
  fetched once into build/unifont/. BMP only; PUA U+E000-F8FF left out (the _all file
  carries CSUR glyphs there; Nerd Font icons live there and belong to the outline font),
  surrogates have none.
- Licence: Unifont is dual-licensed (SIL OFL 1.1, and GPLv2+ with the font embedding
  exception). The kit's pages are taken under **OFL 1.1** (no Reserved Font Name; the
  licence travels with the pages: dist/unifont/OFL-1.1.txt + SOURCE.txt).
- Page file `XX` (high byte of the code point, two upper-case hex digits), big-endian:
  0 "UFP1", 4 page, 5 version 1, 6 glyph count (u16), 8 present bits [32], 40 wide bits
  [32], 72 group offsets [8 x u16, first glyph of each 32-code-point group], 88 glyphs in
  code-point order (narrow 16 bytes, wide 32 bytes: 2 bytes a row). Max 8280 B.
- Installed to SYS:UP-Term/unifont/ (not FONTS:: FixFonts runs at install and scans it).
- Cache: UF_SLOTS = 8 pages per window, LRU, exact-size buffers; missing pages remembered
  (256-bit set) so a missing file is opened once per window.
- Drawing: window font 16 px high -> 1:1; 8 px -> each pair of rows OR'd (2:1 vertical,
  thin strokes survive); a glyph twice the target width -> pixel pairs OR'd across;
  other heights -> the replacement glyph as before. Baseline: Unifont's last ascent row
  (13, or 6 halved) put on the font's tf_Baseline row.
- Order: native (font / drawn lines and blocks) -> outline font (F1, the user's choice)
  -> Unifont (BMP) -> vt_map_glyph's stand-in or replacement.
- Pages read by the outline worker (DOS calls; the handler may not make them): VO_READ;
  a window without an outline font opens an engine-less worker on the first page miss.

## Sizes

- 223 pages, 1,729,864 bytes (narrow pages 4.1-5.8 KB, CJK/Hangul/Indic 8,280 B);
  in the .lha about 0.9 MB more.
- Cache RAM per window: at most 8 x 8,280 B = 66 KB of pages, plus a 128 B chip mask and
  the engine-less worker (vo_font, about 12 KB, only when there is no outline font, from
  the first page read). Latin/Cyrillic/punctuation text: 2-3 pages, about 10-15 KB.

## Notes

- The renderer has no host build (Intuition only). The reachability test drives the
  engine and walks the row through vt_cell_glyph, the function draw_rows and the cursor
  call; the loader's call count is the sentinel. Drawing itself is a rig check.
- DEC double-width/height rows still draw the font's '?' (draw_double_row is untouched).
- Combining marks are still drawn only from the outline font (U3).
