# upkg: install UP-Term add-ons from inside UP-Term

Owner decisions 2026-10-18 (not re-litigated): archives come from GitHub Releases
(`https://github.com/spotUP/vtcon/releases/latest/download/`), upkg runs each package's own
Installer GUI (no unattended mode), CLI first (`upkg list | install <pkg> | update | remove <pkg>`).
Design: plan file ~/.claude-private/plans/eventual-squishing-lemon.md (D1 index from
dist/packages.txt, D2 lhasa as userland `lha`, D3 upkg as a vsh script in UP-Term:bin, D4 https only,
D5 release steps). Gotcha: install logic stays in each archive's Install; upkg never copies files.
