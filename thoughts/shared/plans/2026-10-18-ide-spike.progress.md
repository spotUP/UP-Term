- KEY FINDING: gcc16 has no ixemul dir (-mcrt=ixemul silently falls back to its own newlib-style libc/crt0: wrong). So: `-nostdinc` with gcc16 libstdc++ headers + ixemul headers from ~/opt/amiga (gcc 6.5 install) + sysroot ncursesw headers; link `-nostdlib` with ixemul crt0.o, libscintilla, liblexilla, libncursesw, libixcompat, libstdc++ (gcc16), libm, libgcc, libc (ixemul).
- Mismatch: libstdc++ 16 is configured for a newlib-ish libc; ixemul headers lack C99/wide funcs. Shims (no Scintilla source patched), kept in ide-spike/patches/:
  - ixcompat_cxx.h (-include): declares at_quick_exit/quick_exit/_Exit/strtof/strtold/strtoll/strtoull/wcsto*/vfscanf; skips libstdc++ <cwchar> (defines _GLIBCXX_CWCHAR) and re-exports the few wmem*/mbrtowc names into std; ENOMSG/EIDRM; std::round/lround from libm.
  - inc/mutex, inc/thread, inc/future: single-thread stubs (libstdc++ has no gthreads; Scintilla's layout threads run inline, hardware_concurrency=1).
  - ixlink.cxx: link stubs libstdc++ needs: _impure_ptr (dummy; any libstdc++ stdio path e.g. terminate message would misbehave), __atomic_fetch_add_4, __locale_mb_cur_max, wmem*/wcs* stubs, strtof/strtold via strtod, __xpg_strerror_r.
  - -DPTRDIFF_DOESNT_ALIAS_INT: ixemul ptrdiff_t is long, gcc's PTRDIFF_MAX is int-sized, so RunStyles explicit instantiation was skipped (undefined RunStyles<long,..>).
- Results: libscintilla.a 1.6 MB, liblexilla.a 3.0 MB (all 125 lexers), out/scidemo 5.2 MB with symbols (stripped: see below), hunk header 000003f3 ok (`file`: AmigaOS loadseg()ble). Own demo scidemo.cxx (Lexilla CreateLexer linked statically; jinx uses dlopen, absent on Amiga).
- Unverified/risks for S4/S5: (1) libstdc++16 static init and C++ exceptions under ixemul crt0 (crt0 from 6.5 era; `___init_eh` / ctors may not run) -- first run test; (2) FILE/stdio layout mismatch only matters inside libstdc++ (iostream unused by Scintilla); (3) wchar_t is long in ixemul C headers vs int in C++; same size. (4) Runtime deps: ixemul.library, terminal supporting terminfo for ncursesw (TERMINFO path in UP-Term:), no other shared libs.
- Stripped binary out/scidemo.stripped 4.8 MB (all 125 lexers linked via Lexilla CreateLexer catalogue; trimming to cpp-only would shrink it). Runtime libs seen in binary: ixemul.library, intuition.library, pintui.library (ncursesw port).

- Refuted: "gcc 16 uses .init_array, gcc 6.5 crt0 misses ctors". A test object with one global ctor

- ROOT CAUSE (agent 2026-10-19): under the ixemul crt0 NO C++ global constructor ever runs and no
  EH frame is registered. bebbo's ld only collects `.list___CTOR_LIST__` / `.list___DTOR_LIST__` /
