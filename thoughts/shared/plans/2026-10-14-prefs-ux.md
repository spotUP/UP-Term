# UP-Term Prefs: components that fit the values

Research: `thoughts/shared/research/2026-10-14_prefs-ux.md` (every field, key, valid
values, OS 3.1 availability). Owner request 2026-10-14: font requester for the
fallback font, a colour picker, KingCON style nobody can type, screen mode and depth
through a screen mode requester, "too many regular text inputs".

## Decisions (owner 2026-10-14)

- D1 Colour picker: one shared colour window, colorwheel.gadget + gradientslider.gadget
  (as 3.1 Palette prefs) plus Red/Green/Blue SLIDER_KIND and a hex field, all kept in
  sync. On a screen with too few free pens the wheel degrades; the sliders and hex
  stay exact.
- D2 Layout: font-sensitive (rows and columns from the screen font); falls back to
  topaz 8 when the window would not fit the screen.
- D3 Cancel / close with unsaved edits asks "Discard changes?"; Delete profile asks too.

Decided here (implementation defaults, not owner calls):
- OS floor stays 3.0 (gadtools/intuition V39, asl V38): no ReAction (3.2 only).
- Scrollback: the code is the truth (`vtcon_handler.c:1034-1039`: <= 0 = none, blank =
  500). Control: INTEGER_KIND (1..99999, clamped in code) + checkbox "No scrollback"
  (writes `scrollback = 0`); README line 130 corrected to match.
- KingCON letters (`le_kc_fncmode`, `handler/lineedit.c:1479-1494`; the window menu
  toggles L and B independently, `vtcon_handler.c:2081-2082`): cycle "When several
  names match" = Window (W) / List under the line (L) / Tab cycles (B) / List and Tab
  cycles (LB) / Common part only (C with none of W, L, B); checkboxes "Complete the
  common part first" (C) and "No beeps" (S). Written normalised (e.g. `LC`). The cycle
  and both checkboxes are disabled unless Tab completion = KingCON; ".info in lists"
  and "Directory cache" too.
- Fallback font: ASL file requester on `FONTS:`, pattern `#?.otag`, stores the basename
  (`ASLFO_OTagOnly` is V46, not on 3.1).
- Font: ASL font requester, `ASLFO_FixedWidthOnly`, stores `name:size` with `.font`
  stripped (`open_font` accepts it either way: `render/vtwin.c` strcmp_nocase,
  ".font optional").
- One ASL helper module shared by the handler and Prefs (today `handler/complete.c:843
  asl_pick, 875 font_pick, 953 theme_pick`; Prefs `pick_theme` upprefs.c:617-656 is a
  copy): extracted, both callers use it.
- Help: IDCMP_GADGETHELP (intuition V39 `HelpControl`, `WA_Gadgethelp`) shows a one-line
  help for the gadget under the pointer in the status line. GadTools labels get
  `GT_Underscore` keyboard shortcuts, handled through IDCMP_VANILLAKEY.
- Profiles: CYCLE of the file's profiles + New... / Rename... / Delete (asks); New and
  Rename open a one-field name window.
- Screen mode and depth: button "Choose..." opens the ASL screen mode requester
  (`ASLSM_DoDepth TRUE`, `ASLSM_MinDepth 4`, `ASLSM_MaxDepth 8` = the handler's clamp
  `vtcon_handler.c:2349-2354`, `ASLSM_InitialDisplayID/Depth` from the profile), and
  "Workbench's" clears both keys. The row shows the mode's name (`GetDisplayInfoData`
  DTAG_NAME) and depth. No width/height/overscan gadgets: the handler hardcodes them
  (`vtcon_handler.c:2368-2373`), so they would change nothing. Disabled when Screen =
  Workbench.
- Colour rows: a swatch button (filled with `ObtainBestPenA` of the value, approximate
  by design under dither; released on close) + the hex text (exact value, editable);
  clicking the swatch opens the colour window. Palette entries get the ANSI names
  (Black, Red, Green, Yellow, Blue, Magenta, Cyan, White, Bright ...). Every hex entry
  is validated on commit (today only 3 of 20 are, `upprefs.c:347-359`); `inverse`
  stays a choice for the cursor colour (checkbox "Inverse").
- Gadget ids become a stable named table; `tools/rig/prefs_rig.py` reads ids by label
  through UITREE instead of the hardcoded `ID_SAVE 36`.

## Checklist

Size: S < 2 h, M half a day, L a day+. Host tests run in `make test ONLY=prefs`
(tests/test_prefs.c) unless named.

### Phase A: pure logic in prefs_core (host-tested)

- [ ] **PX1** KingCON: `prefs_kc_decode(letters) -> {match, common, silent}` and
  `prefs_kc_encode(...) -> normalised letters`, decode = `le_kc_fncmode` semantics (call
  it, do not copy it). Test: every letter set round-trips through the handler's
  function to the same mode bits. S.
- [ ] **PX2** Colour: `prefs_hex_parse` strict RRGGBB (`#`/`0x` optional) -> rgb,
  `prefs_hex_format`; `prefs_validate` covers all 20 colour keys and `cursor-color`
  `inverse`. Test: each key with bad input names that field in the error. S.
- [ ] **PX3** Font strings: compose/parse `name:size` from a requester result
  (`topaz.font`, 8 -> `topaz:8`), otag basename from a path. Test incl. odd names. S.
- [ ] **PX4** Scrollback and screen: int with clamp + none flag <-> key; display ID <->
  `0x%08lx`, depth 4..8. Test incl. garbage in old profiles read back sanely. S.
- [ ] **PX5** Dirty tracking: `prefs_equal(a, b)` on the staged tables. Test. S.

### Phase B: shared ASL helper

- [ ] **PX6** `ui/aslpick.c/.h` (or the closest existing shared dir): file, font, screen
  mode requesters; handler `complete.c` and Prefs both call it, the copies are deleted.
  Test: host build of both; rig check through PX15. M.

### Phase C: font-sensitive layout

- [ ] **PX7** Layout as a pure function: rows/columns from font height/width and label
  widths (TextLength-like callback) -> gadget boxes; topaz 8 fallback when the window
  does not fit the screen. Test host: no overlapping boxes, labels fit, fits a 640x200
  NTSC and 640x256 PAL Workbench with topaz 8 and with a 11-pixel font (fallback). M.

### Phase D: components per page (upprefs.c)

- [ ] **PX8** General: Font button + Clear; Fallback font button + Clear; Scrollback
  INTEGER + No scrollback; cursor colour swatch + Inverse; KingCON cycle + 2 checkboxes,
  disabled unless KingCON. M.
- [ ] **PX9** Colors: fg, bg, selected text, selection, 16 named palette swatches + hex,
  Theme... (via PX6). M.
- [ ] **PX10** Advanced: Screen mode "Choose..." / "Workbench's" with name + depth shown,
  disabled when Screen = Workbench; Link command stays text with a "Default" button. S.
- [ ] **PX11** Profiles: cycle + New... / Rename... / Delete (asks), name window. S.

### Phase E: colour window

- [ ] **PX12** Colour window: colorwheel + gradientslider + R/G/B sliders + hex + swatch,
  synced both ways (wheel HSB <-> RGB conversion as a pure host-tested function), pens
  via `WHEEL_MaxPens` / `ObtainBestPenA`, all released; OK/Cancel. Test host: HSB<->RGB
  round trip within 1 step for all 256 grey + 6x6x6 cube values. L.

### Phase F: help, shortcuts, discard

- [ ] **PX13** IDCMP_GADGETHELP help line for every gadget (table of strings, one per
  gadget id; test host: every id has a help string). S.
- [ ] **PX14** `GT_Underscore` shortcuts (unique per page; test host: no duplicate key
  per page), VANILLAKEY handling; Discard changes? on Cancel/close when PX5 says dirty;
  Delete asks. S.

### Phase G: reachability, docs

- [ ] **PX15** ONE rig reachability run, `tools/rig/prefs_rig.py --ui` rewritten (ids
  by label): open Prefs, choose a screen mode in the ASL requester, set a palette entry
  through the colour window's hex/sliders, set KingCON "List and Tab cycles" + No beeps,
  Save; ENV:/ENVARC: profile holds `screen-mode = 0x...`, `screen-depth`, the palette
  entry, `kingcon-mode = LBS` (normalised), `.orig` kept; reopen shows the same values.
  Rig 2 or 3, 060, OS 3.1 image (the floor) and once on 3.2. M.
- [ ] **PX16** Docs: dist/README.txt Prefs section (new controls), README scrollback line
  corrected, ARCHITECTURE/RULES row for the shared ASL helper. S.
