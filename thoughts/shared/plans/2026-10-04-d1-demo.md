# D1: Help > Demo tour

Ledger item D1 in `2026-09-28-vtcon.md`. Branch `feature/d1-demo-menu` (from main 96e64fc).

## Done means

Help > Demo tour (and `/demo`) opens a tab in the window that plays a scripted tour of
everything the terminal does, with a caption per scene; any key ends it and the tab closes,
leaving the user's tab as it was. The tour is UPDemo's (`UPDemo TOUR`), host-tested through
the engine (suite `updemo`); `make test` and `make amiga` clean.

## Design (decided)

- **Player = UPDemo, a new TOUR mode** (demo/updemo.c), not a stream file: one portable
  core, the same scene loop, the same host test harness. A stream cannot answer mouse
  reports, learn the window's size, or end on a key. Show-off scenes are reused in the tour
  (text, colours, scroll regions, effects, the end).
- **Where it runs = a new tab** spawned by the host with tab_spawn (the T1 mechanism), whose
  FROM script runs `C:UPDemo TOUR` then `EndCLI`. Rejected: running UPDemo on the user's own
  stream (needs holding the shell's reads and writes, saving/restoring raw/medium/termios
  modes, and breaks a running program); typing "UPDemo" into the shell (lands in history,
  breaks mid-program). The tab owns its screen: the tour may use the main screen (reflow)
  and resize the window, and nothing of the user's is touched; the tab closes at the end.
- Missing C:UPDemo -> a requester (as Preferences... does for C:UP-Term Prefs).
  No room for a tab (TAB_MAX, foreign window) -> DisplayBeep.
- **Menu**: a Help menu (H9 named it) after Settings, item "Demo tour" -> MENU_DEMO; slash
  `/demo` (SL_ACTION, same id). From a tab the request goes to the host (tab_command).
- **Themes scene**: the palette changes live through OSC 4 / 10 / 11 (what Settings > Theme
  does to the window), reset with OSC 104 / 110 / 111. The four themes' colours come from
  themes/*.conf through tools/gen_tour_themes.py -> demo/tour_themes.inc (committed,
  as vtcaps.inc / glyph_tables.inc are): no second copy of the data.
- **Resize**: DECCOLM with ?40 (the only window resize a program has; CSI 8 t is not in the
  engine, and engine/ + render/ are the speed campaign's). Only when the window is exactly
  80 columns (80 -> 132 -> 80 leaves it as it was); else the scene says how (View menu).
  Every tour scene starts by asking the size (CSI 18 t) so a user resize is followed.
- **Reflow**: on the main screen of the tab, a paragraph, and an invitation to drag the size
  gadget; the size shows in the title (OSC 2).
- **Emoji**: NOT shown -- the owner's rule bans emojis anywhere (UI strings). Shown instead:
  wide CJK, a character beyond the BMP that is not an emoji (mathematical letters), combining
  marks. Flag to the owner.
- Any key ends the tour; mouse reports (SGR) do not -- the mouse scene shows them.
