untouched, `sizeof(vt_cell)` 16.

## Decisions (do not re-litigate)

- **Widths** follow glibc's `localedata/unicode-gen/utf8_gen.py` rules on Unicode 16.0:
  U+00AD 1; U+115F 2; Hangul jungseong/jongseong (HangulSyllableType V/T) 0; Mn, Me 0;
  Default_Ignorable_Code_Point 0; East Asian W/F 2; else 1. Remote programs size text
  with glibc's wcwidth, so matching it is what keeps the cursor in step. Emoji with
  Emoji_Presentation are EAW W, so they are 2 by the same rule.
- **VS16 does not widen** the base (U+2764 U+FE0F stays 1 cell): glibc's wcwidth and
  xterm count it 1; foot/kitty widen only in grapheme mode (?2027), which is not
  implemented. The selector is kept with its base (copy round-trips).
- **Astral code points and combining marks** live in one per-terminal cluster table:
  a cell whose `ch` is in U+D800..U+DFFF (surrogates, never a character in a cell)
  names entry `ch - 0xD800` (up to 2048) holding the base and up to 5 marks.
  Entries are interned (a hash), and freed by a mark-and-sweep over every line (grid,
  alternate screen, scrollback, reflow overflow) when the table is full -- the
  pattern `sweep_styles` uses for `ext`. No cell field changes; cell copies (scroll,
  reflow, resize, scrollback) carry the reference for free. Table full after a sweep:
  astral -> U+FFFD, a mark is dropped.
- **Faint** is the resolved text colour halfway to the cell's background, as RGB
  (default white-ish on black gives about colour 8, as before); palette screens take
  the nearest xterm-256 pen through the existing RGB path. The amiga personality keeps
  its old rule (pens 7/15 become pen 2: its pens have no RGB the engine knows).
- **Clipboard**: write FTXT with CHRS (Latin-1, the system charset of AmigaOS 3.x,
  for every old reader) and a UTF8 chunk (AmigaOS wiki, "UTF8 IFF UTF-8 Unicode
  Text"); read UTF8 when present, else CHRS as Latin-1. No fixed caps.
