# RL21 SELECTA-AA-ICONTEXT: antialiased Workbench icon labels (design, not yet implemented)

Status 2026-11-04: design only. The agent was stopped because the host disk filled up (ENOSPC, no Bash command could run). No code was written and no rig was started.

1. Patched call: graphics.library Text() (LVO -60) through the existing amarchy-flat Text patch (flat_tx.s -> flat_tx_c, tx_install/tx_remove, flat_swap_install/remove, libpatch_done). There is no second patch. It is the same call on both OS: on 3.2, icon.library DrawIconStateA calls Text() once per label (JAM2, fg 1, bg 0, topaz 8, AGA depth 8). On the 3.1 rig, Directory Opus 5 (task "dopus") draws JAM1 Text() on its WFLG_BACKDROP window (RTG 800x600x24). The plain Workbench 3.1 path is the same call, unverified.
2. Filter (pure, iclabel_core): the task name is exactly "Workbench" or "dopus". The rp has a Layer and a Window on the Workbench screen. The box lies inside the window's inner area (not the title or border). The draw mode is JAM1 or JAM2 with no COMPLEMENT or INVERSVID, and APen != BPen. The new branch runs only when the TITLE-ACCENT and BUTTON-FILL branches did not take the call, and only when r->st.enabled && !r->st.held.
3. How the backdrop is read: box x = cp_x, y = cp_y - tf_Baseline, w = TextLength(), h = tf_YSize. Before: read the box once (JAM1 only). Then call the saved Text() with a6 = GfxBase (the s28 rule); it advances cp_x itself, so the metrics stay exact. After: read the box again. Reads use cgx ReadPixelArray RGBA at depth > 8 (57 us per label), else ReadPixelArray8 with a temprp. Never use a ReadPixel loop.
4. Mask (pure): JAM2: set = after == APen, and every background is BPen (the stock box, which is exactly what is on screen). JAM1: set = after != before, and the background is `before` at each pixel (the real backdrop).
5. Coverage (pure): set pixels get 255. An unset pixel with two orthogonal set neighbours at a corner (N+E, N+W, S+E, S+W) gets partial coverage: about 96 for one corner, about 160 for two or more. The font, box and advance are WB's own. A TrueType swap was rejected because WB sizes the boxes from its own font.
6. Blend (pure): RTG: out = ce_mix(fg, bg_px, cov), then cgx WritePixelArray RGBA. Pen screens: k = aa_ink_index(cov, n) with n = aa_ink_shades_for_depth(depth). k = 0 keeps the background pen; k = n+1 is APen. Otherwise the target is ce_mix(fg, bg, aa_ink_level(k, n)), the candidate is ObtainBestPen, and the candidate is kept only if aa_ink_shade_accept(pm_dist(...)) passes (render/pen_match.h); if not, round to fg or bg. Results are cached per (bg pen, k), and the result goes back through WritePixelArray8.
7. Memory and stack: the buffers are AllocVec'd once at install, never on the stack (the call runs on the Workbench or dopus task stack). A SignalSemaphore guards them: AttemptSemaphore, and on contention the call falls back to stock Text. Buffers and obtained pens are freed only after a successful tx_remove, under ObtainSemaphore. Pens are freed only if the WB colormap pointer is unchanged.
8. Chain safety: install and remove are the existing tx_install and tx_remove. When the patch is "still chained", amarchy-flat stays resident and frees nothing.
9. Sentinels for the rig: STATUS gains `labels=<n>` (labels blended) and `lskip=<n>` (fallbacks). Proof: edge pixels lie strictly between fg and bg, measured from shots; 5 drawer drag/reopen/redraw cycles; Amarchy quit leaves labels=0 calls with stock pixels.
10. Host test (tests/test_iclabel.c, suite "iclabel" in tests/test_main.c and VTTEST_HOST_SRC): filter accept/reject cases, the JAM1/JAM2 mask, corner coverage values, the RTG blend (exact ce_mix numbers), and pen shade accept/refuse. Each case must fail if the matching function is reverted to stock (cov = mask).
