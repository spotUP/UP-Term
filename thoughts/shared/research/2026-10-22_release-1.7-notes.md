# UP-Term 1.7 release notes (draft)

Range: vtcon v1.6..HEAD (16 commits, v1.6 dated 2026-10-21) and upterm-ports commits since that date (7).

## Release notes draft

- upkg browse: the browser now starts from lists written in one upkg load, shows package information boxes, row colours, message boxes and a program box, and no longer flashes the Shell between upkg-ui screens.
- upkg-ui: new message box, text box and program box screens, button labels and colour codes; it reads keys from a terminal and exits with code 3 when the keys end; it stays on the normal screen.
- upkg (opkg): new command `upkg list-new`; upkg output is line-buffered when sent through a pipe; no upkg command ends silently when it does nothing (patches 0018 to 0024 in upterm-ports).
- Installer: Update is now offered over an install that recorded no options, and says why when it cannot; the drawer an Update restores is read back as the install named it.
- vsh: the default prompt shows the full Amiga path; completion works on names in the current drawer before a history line.
- Console: Amiga pens 0 and 1 are drawn with the window ground colour in a CON: window.
- Version stamps: every base program (UPTerm, the handlers, vsh and others) now carries the base version in its $VER string, and Claude carries the up-claude version.
- Development only: rig and test fixes (a rig without a system disk is refused, base-move check, PATH for terminal-case scripts, dist check of the full-width WINDOW tooltype).

## Proposed version bumps
