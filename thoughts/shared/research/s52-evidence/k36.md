## Design note
vtwin anim_tick re-arms at the normal frame-clock cadence, not min(due, blink period): frame_start is a no-op while a
request is in flight, so a long timer would delay output. vt_anim_tick returns -1 with no running animation, so no
re-arm and no work per frame when nothing animates. Paused when hidden or scrolled back (vt_anim_paused).
PROF line: `PROF kitty anim switches/ticks` = cumulative vt_kitty_frame_switches and EClock ticks in animation redraws.
