## 3. Constraints found

- Hires screen 640x256, pixel aspect 1:2 (tall pixels); half-block pixel scenes use W x 2R; scene text is 80 columns (resize scene handles 132).
- Must run on 68020 and 060: keep per-frame work small; kitty pictures should be uploaded once and then placed (a=p) or animated by the terminal (a=a), never re-encoded per frame. Existing pixel scenes are capped at 25 fps and benchmarked (bench flag).
- Media must be loaded by name through `io->load` from UP-Term:share/updemo (see kitty_earth, line 1888); a missing file must fall back to coded art (earth does). Kit staging: tests/test_rig_media_drift stages KIT_MEDIA files; any new file needs adding there and to the dist build.
- Animation gaps: with f=100 PNG frames, z (gap) on `a=f` is EINVAL; set gaps with `a=a,r=N,z=ms` (as sc_kitty_anim does).
- Every stale-install failure so far ("15 squares", rig 91) was a missing earth.anim: new media scenes need the visible fallback caption.
- Keep screen-reading honest: 160 px frames is the current earth size; a photo must be pre-scaled (about 320x160 at hires, aspect-corrected) to keep upload small.

## 4. Proposed scenes (4-8)

1. **picture** (new, photo): kitty f=100 PNG of picsum 1015 (fjord), uploaded once (a=T), then shown at two sizes via c=/r= scaling; caption notes the 1:2 pixel aspect is corrected (IMAGE-ASPECT-HIRES) with a coded circle drawn beside it that must look round. Needs: `fjord.png` (~320x200, PNG, pre-scaled, under ~60 KB) in dist/updemo + KIT_MEDIA; fallback: coded gradient.
2. **icat** (new): the scene types `icat fjord.png` into a real vsh line (or prints the command beside it) and shows the output flowing in the scrollback. Needs: VTC:icat in the install (already shipped), same fjord.png. Marked partly demo-only if no shell is attached to the scene.
3. **kitty placement** (new): upload one small picture, place it at several cells with a=p (different i/p ids), move one with a=p again, delete with a=d,d=i, and show child placement relative to a parent (P=,Q=,H=,V=). Needs: generated sphere from the truecolour scene (no new media).
4. **splits** (change): replace the key table by a real split: run the Right Amiga D equivalent through a slash command (as tabs scene does with /tab new), fill both panes with text, zoom, close. Needs: whichever /split slash line exists (verify in the keymap action table before coding).
5. **earth + photo combo / animation** (change): keep earth.anim, add the fjord picture behind it with z=-1 to show animation over a still, which exercises K36 timing plus z-index in one picture. Needs: both media files.
6. **help** (new): show the welcome text and `/help`, `/tutorial` and `/ask` lines as printed text (no spawn on the demo screen); one line each. Needs: no media.
7. **nerd fallback** (change to glyphs): add a row that names the fallback font (SymbolsNerdFontMono) and a larger icon row proving the grid-fitted stems; no media.
8. **why** (optional, vsh): one vsh line showing the `why` builtin explaining an exit code; needs a command that fails first.

Priority: 1, 3, 4 give the most visible new content; 2 and 6 are cheap; 5, 7, 8 are polish.
