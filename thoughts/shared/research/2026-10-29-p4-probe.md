# P4 probe log (R4.1)

Rig 4, `UPTERM_RIG=4`, 060, cybergraphics.library V41 open. Raw output: shotprobe runs on RAM:shotprobe.

- (a) OK. Own chipset screen 320x200x4 (modeid 0x00021000, IsCyberModeID=0): WritePixelArray8 then
  ReadPixelArray8 32x16: 0 of 512 bytes differ. ReadPixelArray8 is a faithful read on chipset screens.
- (b) Workbench 800x600 depth 24 modeid 0x50041303, IsCyberModeID true.
  - ReadPixelArray8 of 16x1 at 100,100: all 16 bytes become 00. Useless on a 24-bit screen.
  - First attempt used LVO -126, which is WritePixelArray. The FD (amiga-gcc15 cybergraphics_lib.fd, bias
    30, private entries skipped) gives ReadPixelArray = -120, WritePixelArray = -126, FillPixelArray = -150.
    With -120: ReadPixelArray rc=16 (pixel count). Pixels never drawn at 100,100 stayed at the prefill
    (0x11111111) for RECTFMT 0/1/2.
  - After FillPixelArray 0x00FF8040 at 100,100 16x1, ReadPixelArray RECTFMT_ARGB (2) returns 00ff8040 for
    pixel 0 and pixel 15. So cgx ReadPixelArray reads back RTG truecolour correctly; R4.3 on RTG must use it.
  - Open: why the untouched pixel left the prefill unchanged (probably a not-yet-drawn region); the fill
    read-back proves the path works.
- (c) png.datatype present (SYS:Classes/DataTypes/png.datatype, DEVS:DataTypes/PNG). NewDTObject with
  DTA_BaseName "png" + DTST_RAM failed, so DTM_WRITE was not reached; RAM:probe.png not created.
  Inconclusive. Owner already chose IFF ILBM only (D1), so no further work.
- (d) OK. clipboard.device unit 0: CMD_WRITE of a 324036-byte FORM ILBM (800x400 d8, made by shot_core) +
  CMD_UPDATE, read back whole: 324036 bytes equal.
- (e) `Reboot DRYRUN` (our build/amiga/Reboot; C:Reboot of OS 3.2 ignores DRYRUN and reboots the rig):
  lines "Reboot: Ram Disk: flushed", "VTCX:", "Rushhours:", "System:", "BOOTX:" all flushed, none named
  as unanswered. Exit code not captured separately by ami.py exec output (source: 0 when all answered).

## Conclusions for R4.3+

- Chipset/8-bit screens: ReadPixelArray8 + temp RastPort works.
- RTG truecolour: use cgx ReadPixelArray (LVO -120, a0 dest, d0 dx, d1 dy, d2 mod, a1 rp, d3 sx, d4 sy,
  d5 w, d6 h, d7 fmt) with RECTFMT_ARGB, then quantise or write a deep ILBM.
- Clipboard takes a 300 KB FORM ILBM.
